# Изображения Happy Foxy

## Отзывы

Положите 6 горизонтальных изображений в папку `media/reviews/`:

- `review-1.png`
- `review-2.png`
- `review-3.png`
- `review-4.png`
- `review-5.png`
- `review-6.png`

Рекомендуемый размер: от 1200 x 675 px, соотношение сторон 16:9.
Используйте PNG. На изображении должен быть только сам отзыв, без дополнительного текста на сайте.

## Уже используемые папки

- `media/logo/` - `Лого.png`, аватар Foxy и фотография для первого экрана
- `media/teachers/` - портреты Анжелики и Дарьи
- `media/gallery/` - фотографии занятий, квестов, лагеря и мастер-классов
