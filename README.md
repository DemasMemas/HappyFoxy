# Happy Foxy English Club

Одностраничный сайт для студии английского языка в Балашихе.

## Что уже готово

- адаптивный лендинг на чистом HTML/CSS/JS
- 7 секций по ТЗ
- базовая анимация появления блоков
- структура папок под изображения

## Что заменить в первую очередь

- `media/logo/logo.svg`
- `media/hero/hero.svg`
- `media/teachers/teacher-1.svg`
- `media/teachers/teacher-2.svg`

## Открытие

Просто откройте `index.html` в браузере.

## Отправка заявок на почту

Форма отправляет имя, телефон, направление и необязательный комментарий на
`happyfoxyclub@yandex.ru` через `send.php` по SMTP Яндекса.

Перед публикацией на PHP-хостинге:

1. Загрузите `send.php` и `send-config.php` в одну папку с `index.html`.
2. Укажите пароль приложения Яндекса через переменную окружения
   `HAPPY_FOXY_SMTP_PASSWORD`.
3. Если хостинг не поддерживает переменные окружения, откройте `send-config.php`
   на сервере и замените `PASTE_YANDEX_APP_PASSWORD_HERE` на пароль приложения.
4. Проверьте отправку тестовой заявкой.

SMTP: `smtp.yandex.ru`, порт `465`, SSL. Основной пароль от Яндекс ID для формы
не используется.
